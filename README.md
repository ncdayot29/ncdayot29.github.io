Nica Jane Dayot - Personal Portfolio & Resume

Welcome to my portfolio repository! This project serves as a showcase of my web development projects, UI/UX designs, education, and technical background as a 4th-year Information Technology student.

---

Features

Responsive Portfolio (`index.html`): Features sections for About Me, Skills, Projects, Education, Certificates, and Contact details with a pastel pink aesthetic.
Printable Resume (`resume.html`): A single-page, print-ready HTML resume formatted to export directly to PDF.
Interactive Previews: Links to live demos on Netlify and Figma design prototypes.
Certificate Gallery: Scaled preview cards with external links to view full-size certificates.

---

Built With

HTML5 - Page structure and semantically organized content
CSS3 - Custom styling, CSS Grid, Flexbox, variables, and media queries for mobile responsiveness
Google Fonts - Plus Jakarta Sans & Playfair Display
